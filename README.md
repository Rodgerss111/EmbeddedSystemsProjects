## 📌 Highlight Projects

### 1. Smart Egg Grading System (IoT + Automation)
  An IoT-based system using Arduino, HX711, servo motors, and ESP32 to classify eggs by weight, display data on LCDs, and send data to ThingSpeak for cloud monitoring.

[View Project Folder](./Project-01_SmartEgg Grader A Weight Sensor-Based IoT Egg)

Project-01_SmartEgg Grader A Weight Sensor-Based IoT Egg

### 2. Dual Mode Real-Time Cap Sorting System Using Arduino Uno
  This project is a real-time plastic bottle cap sorting machine using Arduino Uno, combining automation and embedded systems for efficient recycling. It uses a color sensor and servo motor for automatic sorting, a keypad for manual control, and an LCD for real-time feedback, offering a small-scale yet effective approach to sustainable waste management.

[View Project Folder](./Project-02_Dual Mode Real-Time Cap Sorting System Using Arduino Uno)
